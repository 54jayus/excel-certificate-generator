excel-certificate-generator

一个面向真实办公场景的 Excel VBA 批量生成工具。适合证书、桌牌、标签、参会证等固定版式内容，准备模板和数据后即可批量输出结果。

功能 01

模板样式编辑

支持在模板 Sheet 中自由调整行高、列宽、字体、边框与排版结构。

功能 02

数据批量写入

通过占位符匹配数据字段，将姓名、部门、编号等内容自动批量填入模板。

功能 03

分页与排布控制

支持单页数量、分页字段和页面排布控制，适合打印与分发场景。

功能 04

结果快速生成

将模板样式与数据内容合并输出，减少重复复制粘贴带来的手工劳动。
